Academic Project · MSc Bioinformatics · 2025

Breast Cancer Subtype Classifier from Genomic Copy Number Data

Contributed to a group project comparing classification pipelines for HER2+ breast cancer subtype identification using array CGH data. I owned the interpretable baseline pipeline, combining ANOVA-based feature selection with logistic regression under a nested cross-validation framework. The project compared this approach against a higher-complexity SPLS-DA + XGBoost workflow, with the main goal of building a rigorous, leakage-aware modeling process rather than simply maximizing performance. Because HER2+ status is strongly linked to ERBB2 amplification, interpretation focused on whether the models recovered the expected chromosome 17 signal.

Python SPLS-DA Statistical Analysis ANOVA XGBoost scikit-learn SHAP Feature Selection aCGH Data
